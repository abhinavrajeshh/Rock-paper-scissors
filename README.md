# 🎮 Rock Paper Scissors (JavaScript)

A simple **Rock Paper Scissors game** built using JavaScript as part of my learning journey.

This project is played entirely in the **browser console** and focuses on core programming concepts like functions, logic building, and problem solving.

---

## 🚀 Features

- Random computer choice using `Math.random()`
- User input via `prompt()`
- Case-insensitive input handling
- Input validation (basic)
- 5-round game system
- Score tracking (Player vs Computer)
- Final winner announcement

---

## 🧠 Concepts Practiced

- Functions and return values  
- Conditional statements (`if / else`)  
- Logical operators (`&&`, `||`)  
- Loops (`for`)  
- String methods (`toLowerCase()`, `trim()`)  
- Problem-solving and pseudocode  

---

## 🛠️ How to Run

1. Clone the repository
2. Open `index.html` in your browser
3. Open the browser console
4. Follow the prompt instructions to play
